# Deno Deploy → Cloudflare Workers Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run the existing Open Congress API (Hono REST API + SSR view pages) on Cloudflare Workers instead of Deno Deploy, with identical routes and response shapes.

**Architecture:** The Hono app stays as-is and becomes the Worker's default export. The Neo4j driver (`neo4j-driver-lite`, Bolt over TCP/WebSocket, a module-level connection pool) is replaced by a small `fetch` client for Neo4j's HTTPS **Query API v2** (`POST {httpUrl}/db/{database}/query/v2`), because Bolt is not reliable on Workers and Workers forbid reusing one request's socket in another. Config comes from Worker bindings via `import { env } from "cloudflare:workers"`, so the ~30 `runQuery(...)` call sites do not change.

**Tech Stack:** Cloudflare Workers, Wrangler 4, Hono 4.13, @hono/zod-openapi 1.x + zod 4, @hono/swagger-ui 0.6, Vitest 4 + @cloudflare/vitest-pool-workers, TypeScript 5.9, npm.

**Spec:** The user's request: "This was previously using Deno + Hono + Deno Deploy. Deno Deploy is now being deprecated. Move this whole functionality to Cloudflare Workers." The spec is therefore *the current behaviour*: every route in `main.ts`, `README.md` and `API.md` must keep working with the same paths, status codes and JSON shapes.

## Global Constraints

- Package manager: **npm** (commit `package-lock.json`). Node ≥ 20.
- Versions (caret ranges): `hono@^4.13.0`, `@hono/zod-openapi@^1.6.0`, `zod@^4.1.0`, `@hono/swagger-ui@^0.6.0`; dev: `wrangler@^4`, `vitest@~4.1.0` (the pool requires `^4.1`, NOT vitest 5), `@cloudflare/vitest-pool-workers@^0.23.0`, `typescript@~5.9.0`.
- Remove entirely: `deno.json`, `deno.lock`, `neo4j-driver-lite`, `dotenv`, every `Deno.*` call.
- Worker name: `open-congress-api`. Entry: `main.ts` (keep the file where it is; do not move sources into `src/`).
- `wrangler.jsonc`: `compatibility_date: "2026-11-01"` (if the installed workerd rejects it as too new, use the newest date it accepts), `observability.enabled: true`, `assets.directory: "./static"`, no `nodejs_compat` flag (nothing needs it after the driver is gone). Custom-domain route for `open-congress-api.bettergov.ph` goes in as a **commented-out** block; deploying it is the user's call.
- Env/bindings (names fixed): `NEO4J_URI`, `NEO4J_USERNAME`, `NEO4J_PASSWORD` (secret), optional `NEO4J_HTTP_URL`, optional `NEO4J_DATABASE` (default `"neo4j"`). Local secrets live in `.dev.vars` (gitignored); `.env.example` is replaced by `.dev.vars.example`.
- Never read env at module top level in a way that throws; a missing secret must surface as the existing 500 JSON error, not a Worker crash.
- Keep `.ts`/`.tsx` extensions in import specifiers (`allowImportingTsExtensions`), but replace every `@/` alias with a relative path (18 occurrences) so wrangler/esbuild and vitest need no alias config.
- Workers free plan allows 50 subrequests per request: one Neo4j query = one subrequest. Do not add queries to existing handlers.
- Commit messages: conventional (`feat:`, `chore:`, `test:`, `docs:`), **no AI attribution lines** (org rule).

## Review Focus

1. **Neo4j returns an HTTP error** (401 bad credentials, 400 Cypher error, 5xx): `runQuery` throws an `Error` whose message contains the Neo4j error `code` and `message`; route handlers keep returning their existing `{ success:false, error:{...} }` 500. → Task 2 test `throws with Neo4j error code on non-2xx`, Task 3 test `ping returns 500 when database rejects`.
2. **SKIP/LIMIT parameters must reach Neo4j as integers**, not strings or floats. `int(n)` must return a whole JS number so JSON serialises `20`, not `20.5`/`"20"`. → Task 3 test `people list sends integer limit/offset`.
3. **Null properties** (e.g. `middle_name: null`) must stay `null` in API output, not be dropped. → Task 2 test `keeps null values`.
4. **Missing secrets** produce a clear `Missing Neo4j connection environment variables` error inside the normal 500 JSON, not an exception at import. → Task 2 test `throws when credentials are missing`.
5. **Existing Bolt-style `NEO4J_URI` values** (Aura `neo4j+s://xxx.databases.neo4j.io`, local `neo4j://localhost`, `bolt://localhost:7687`) must keep working without the user adding `NEO4J_HTTP_URL`. → Task 2 `resolveHttpUrl` tests.

### Task 2: Neo4j Query API client

**Files:**
- Rewrite: `lib/neo4j.ts`
- Modify: `routes/ping.ts`
- Create: `test/helpers/query-api.ts`, `test/neo4j.test.ts`

**Interfaces:**
- Consumes: Worker bindings via `import { env } from "cloudflare:workers"` (cast to a local `Neo4jEnv` interface with the five `NEO4J_*` names, all `string | undefined`).
- Produces (all exported from `lib/neo4j.ts`):
  - `resolveHttpUrl(e: Neo4jEnv): string` — base URL, no trailing slash.
  - `normalizeValue(v: unknown): unknown`
  - `runQuery<T extends Record<string, unknown> = Record<string, unknown>>(cypher: string, params?: Record<string, unknown>): Promise<T[]>` — same signature as before.
  - `verifyConnectivity(): Promise<void>`
  - `int(n: number): number` — `Math.trunc(n)`; keeps the existing `int(...)` call sites compiling.
  - `test/helpers/query-api.ts`: `mockQueryApi(handler: (req: { statement: string; parameters: Record<string, unknown>; url: string; headers: Headers }) => { fields: string[]; values: unknown[][] } | Response)` → returns the `vi.spyOn(globalThis, "fetch")` spy; wraps a plain result as `new Response(JSON.stringify({ data: { fields, values }, bookmarks: [] }), { status: 200, headers: { "content-type": "application/json" } })`.

Query API contract (plain JSON, the default):
- Request: `POST {httpUrl}/db/{database}/query/v2`, headers `Authorization: Basic btoa(user:pass)`, `Content-Type: application/json`, `Accept: application/json`; body `{ "statement": cypher, "parameters": params ?? {} }`.
- Success: `{ "data": { "fields": string[], "values": unknown[][] }, "bookmarks": [...] }`. Integers are JSON numbers. Nodes/relationships are objects with `elementId` and `properties`.
- Failure: non-2xx with `{ "errors": [{ "code": string, "message": string }] }`.

- [ ] **Step 1: Write `test/neo4j.test.ts`:**
  - `resolveHttpUrl`:
    - `{ NEO4J_HTTP_URL: "https://x.example/" }` → `"https://x.example"` (explicit wins, trailing slash stripped).
    - `{ NEO4J_URI: "neo4j+s://abc.databases.neo4j.io" }` → `"https://abc.databases.neo4j.io"`.
    - `{ NEO4J_URI: "bolt+s://db.example.com:7687" }` → `"https://db.example.com"`.
    - `{ NEO4J_URI: "neo4j://localhost" }` → `"http://localhost:7474"`.
    - `{ NEO4J_URI: "bolt://localhost:7687" }` → `"http://localhost:7474"`.
    - `{}` → throws `/Missing Neo4j connection environment variables/`.
  - `normalizeValue`:
    - `{ elementId: "4:x:1", labels: ["Person"], properties: { id: "p1" } }` → `{ id: "p1" }`.
    - `[{ elementId: "e", labels: [], properties: { a: 1 } }, 2]` → `[{ a: 1 }, 2]`.
    - `{ name: "x", count: 3 }` (plain map) → unchanged.
    - `null` → `null`.
  - `runQuery`:
    - `posts statement and parameters`: with `mockQueryApi`, `runQuery("RETURN $x AS x", { x: 5 })` → the spy got URL `https://test.databases.neo4j.io/db/neo4j/query/v2`, method POST, `Authorization` = `"Basic " + btoa("neo4j:test-password")`, body `{ statement: "RETURN $x AS x", parameters: { x: 5 } }`.
    - `maps fields to records`: response `fields ["id","n"]`, `values [["a",1],["b",2]]` → `[{ id:"a", n:1 }, { id:"b", n:2 }]`.
    - `keeps null values`: `fields ["middle_name"]`, `values [[null]]` → `[{ middle_name: null }]` (key present).
    - `throws with Neo4j error code on non-2xx`: handler returns `new Response(JSON.stringify({ errors: [{ code: "Neo.ClientError.Security.Unauthorized", message: "bad creds" }] }), { status: 401 })` → rejects with message containing `Neo.ClientError.Security.Unauthorized` and `bad creds`.
    - `throws when credentials are missing`: call the exported config path with `NEO4J_USERNAME` unset (use `resolveConfig`-style injection or `vi.mock("cloudflare:workers")`; pick one and use it consistently) → rejects `/Missing Neo4j connection environment variables/`.
  - `verifyConnectivity`: resolves when the mock answers `RETURN 1 AS ok` with `[[1]]`; rejects when the mock returns 500.
- [ ] **Step 2: Run `npx vitest run test/neo4j.test.ts`** → FAIL (exports missing).
- [ ] **Step 3: Rewrite `lib/neo4j.ts`** to the interfaces above. Read `env` inside functions, never at import. `normalizeValue` recurses into arrays and turns any object with both `elementId` and `properties` into its `properties`; other objects are returned unchanged (Query API already returns plain numbers, so the old `.low/.high` handling goes away). Remove `getDriver`, `getSession`, `closeDriver`, `runWrite` (nothing outside `ping.ts` uses them; `runWrite` has zero callers). If the error body is not JSON, throw `Neo4j Query API error: HTTP <status>`.
- [ ] **Step 4: Update `routes/ping.ts`** to `await verifyConnectivity()` in place of `getDriver().verifyConnectivity()`. The response shape stays the same.

## Out of scope / for the user

- Setting real Cloudflare secrets, attaching the custom domain, and cutting DNS over from Deno Deploy.
- Confirming the production Neo4j exposes the Query API over HTTPS (Aura: yes, on the same host as the `neo4j+s://` URI; self-hosted: port 7473/7474 must be publicly reachable with TLS, Neo4j ≥ 5.19).
- Adding caching (Cache API / `Cache-Control` on read-only endpoints) is a sensible follow-up but changes behaviour, so it is not part of this migration.
